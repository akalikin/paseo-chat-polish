Chat Polish redraws the agent timeline as one quiet column and adds the One Dark Darker Mariana theme.

Tool calls become single rows: an icon, a verb whose tense shows the state (Running, Ran), the command or file, and a short detail such as duration, diff counts or match counts. Tap a row to open its output, diff, matches or raw input and output. Running calls pulse, failed calls turn their icon red and show the exit code or error, and canceled calls are dimmed and struck through. Reasoning collapses to a Thinking or Thought row you can open. Plans render as a card, task lists show progress, errors appear inline in red, and context compaction appears as a thin divider.

Assistant and user messages keep Paseo's native rendering. On desktop they are restyled to the design, and the Rich text page offers three styles each for quotes, tables, code blocks, inline code, headings, lists and task lists, callouts (> [!NOTE], [!WARNING], [!TIP]) and horizontal rules. Because the plugin replaces each tool call, Paseo no longer groups consecutive tool calls into one summary line.

Chat Polish adds a sidebar entry that opens a theme dashboard. Pick a preset (One Dark Darker Mariana, Paper or Dusk) or edit the eight theme colors, check their contrast, and watch a live chat preview update as you type. Apply saves the theme on the host; select it under Settings, Appearance to use it app-wide. Images that an agent posts on their own show as thumbnails and open full size when tapped. On desktop, images inside a reply with text, such as tool screenshots, shrink to the same thumbnails. On desktop, rows follow your Appearance fonts and sizes and the Always expand reasoning setting. On desktop, the composer's model picker gains a provider rail on the left. Providers you can't switch to in an existing chat are dimmed, with a note saying why. The thinking picker marks each model's default level and shows level descriptions where the provider has them. A short note appears when switching models moves thinking to the new model's default. The context window card on the composer gets a larger usage figure with a bar, cleaner limit rows and a footer for account details. Code blocks show the language their fence names, and tables can add hairlines between columns. Mermaid diagrams take the app theme's colors: raised nodes with thin borders, muted edges and accent-tinted notes. Thought and tool rows fade back until you hover or open them. On desktop and web, the thoughts and tool calls between two replies merge into one row, such as “Thought 2 times, edited 1 file, and ran 3 commands”, with the time they took. While the agent works, the row names the step in progress. A failed step turns its icon red. Open the row to see each step with colored commands and output. Turn merging off on the Messages page or from the Command Center. Row icons can be hidden there too, separately for merged rows, tool calls and thoughts; a row without its icon starts with its verb, and a failed step's verb turns red. The composer is more compact: an empty box is one line tall and grows as you type, the focus hint is hidden, and its chips and buttons share one 26px row. The working indicator's dots animate smoothly, or, from the Messages page, become another loader (sparkle, spokes, dot ring, orb, matrix ripple or snake) at 14, 16 or 18pt. After a turn that changed files or had a failing command, a recap row lists the files with lines added and removed, the commands run, and the ones that failed; it opens to the details. On desktop, ⌥⌘↑ and ⌥⌘↓ jump between your messages in a chat. The Command Center (⌘K) has Previous prompt and Next prompt, plus Chat Polish toggles for merged steps, row icons, faded rows, hiding finished reads and searches, turn recaps and the restyle of Paseo's own items. Copy last turn as Markdown in the Command Center copies your prompt, the reply and the changes. On desktop, the context window card gains a Compact button that sends /compact to the chat, hidden while the agent is working. Queued messages show as a dashed row with a clock, a “Queued” label and quiet edit and send-now icons. The model, thinking and mode pickers, the context card and the outline preview fade and rise in.
